# The Base Model Is Dead — Varun Singh, Arcee AI

## TL;DR
Varun Singh, pre-training lead at Arcee AI, argues that the classical "base model"—trained predominantly on raw web text to reflect general human knowledge—is being replaced by models purpose-built as priors for reinforcement learning and agentic tasks. Modern pre-training mixes are dominated by code, STEM, and synthetic data, with post-training-style data pulled earlier into the pipeline and RL commanding an increasingly equal or greater share of the compute budget.

## Key Takeaways
- The classical base model paradigm (GPT-3 era) relied on ~85% web text (Common Crawl, WebText, Wikipedia) to encode general human knowledge, with post-training mainly adapting the model to a chat interface.
- OpenAI's o1 and DeepSeek's R1 shifted RL from a "cherry on top" to a core driver of model capability, especially for reasoning and agentic tasks.
- Web text has dropped dramatically in modern pre-training mixes—down to ~15% in models like MAI Thinking 1—while code and STEM data now dominate.
- Two contrasting approaches exist: MAI Thinking 1 avoids synthetic data entirely, while NVIDIA's NeMo Tron 3 Ultra heavily incorporates synthetic and SFT-style data directly into pre-training.
- Synthetic data is used at scale for rephrasing, upsampling, and quality improvement, as demonstrated by Arcee's Trinity Lodge and Kimi-K2, rather than blindly injecting data that could cause model collapse.
- Pulling post-training-style conversational data into pre-training helps models learn task representations and conversation shapes from the very beginning.
- For Mixture-of-Experts (MoE) models, including post-training-distribution data early prevents severe load-balancing problems caused by distribution shift between pre-training and post-training.
- "Mid-training" is emerging as a phase to expose models to agentic traces and longer contexts, though Singh argues the boundary between phases is blurring.
- Compute allocation is shifting: Xiaomi's MiMo lab reports roughly equal compute for pre-training and post-training, while Kimi's Composer 2.5 allocated more compute to RL than to supervised learning.
- The base model should now be understood as building "atomic skills" and priors for RL-driven reasoning and agentic behavior, rather than merely encoding internet-scale human knowledge.

## Detailed Breakdown

### The Classical Base Model Paradigm [00:12](https://www.youtube.com/watch?v=xbPriQWXtWM&t=12s)
Singh introduces the talk by framing the traditional base model as a reflection of the entirety of human internet knowledge, built through large-scale next-token prediction on web text. He references training diagrams from Arcee AI's own models, GLM 4.5, and GLM 5, all of which share a pre-training phase where the model accumulates world knowledge and builds useful representations.

### Pre-Training in the GPT-3 and Llama 3 Era [01:13](https://www.youtube.com/watch?v=xbPriQWXtWM&t=73s)
Using a simplified decoder-only transformer diagram and the GPT-3 paper, Singh explains how early base models learned in-context learning through self-supervised next-token prediction. GPT-3's training data was roughly 85% web text (Common Crawl, WebText-2, Wikipedia, books). By Llama 3, web text still comprised ~50% of tokens. Post-training was minimal—mostly adapting the model to a chat template and Q&A format—with RL serving as a "cherry on top" that shaped interaction flavor rather than conferring new knowledge.

### The Reasoning Model Shift [03:50](https://www.youtube.com/watch?v=xbPriQWXtWM&t=230s)
The paradigm shifted with OpenAI's o1 (2024) and DeepSeek's R1 (January 2025), which pioneered reasoning models and demonstrated that RL could dramatically improve performance on tasks like competitive math (AIME). The emergence of tools like Claude Code showed that models could learn to interact with software environments end-to-end through RL, raising the question of whether the standard base model remains the best prior for this new RL-heavy phase.

### Contrasting Pre-Training Data Strategies [05:54](https://www.youtube.com/watch?v=xbPriQWXtWM&t=354s)
Singh presents two contrasting approaches. MAI Thinking 1 explicitly avoids synthetic data and filters web text to exclude other language models' outputs, adhering to the classical paradigm of bootstrapping from human knowledge—but even here, web text has dropped to just 15% of the training mix, with code and STEM dominating. In contrast, NeMo Tron 3 Ultra pulls SFT-style question-answer chat data back into pre-training, allowing the model to learn the shape of downstream tasks from the very beginning, while also heavily reducing web text proportion.

### Synthetic Data at Scale [09:03](https://www.youtube.com/watch?v=xbPriQWXtWM&t=543s)
Addressing concerns about model collapse from synthetic data, Singh highlights successful large-scale applications. Arcee's Trinity Lodge used web-scale synthetic rephrasing—taking seed data items and generating multiple rephrasings so the model sees the same information in varied ways. Kimi-K2 applied synthetic techniques broadly across its entire pre-training dataset. Earlier examples include the Swallow Code and Swallow Math datasets. The trend shows synthetic data not only increases token count but also improves quality and shapes tokens toward instruct/agentic task representations early in training.

### MoE Load Balancing and Distribution Shift [11:06](https://www.youtube.com/watch?v=xbPriQWXtWM&t=666s)
For Mixture-of-Experts models, Singh identifies load balancing as a major pain point. Without post-training-distribution data in early pre-training, the model faces severe distribution shift between pre-training and post-training, causing expert utilization imbalances. MAI Thinking 1 overcame this by aggressively increasing the load-balancing coefficient during SFT, but Singh argues it is better to include the post-training distribution early so the model learns stable representations from the start.

### Mid-Training and Blurring Phase Boundaries [12:38](https://www.youtube.com/watch?v=xbPriQWXtWM&t=758s)
Singh discusses the emerging "mid-training" phase, which exposes models to post-training-like distributions, longer contexts, and agentic traces. However, he argues that the traditional pre-training/mid-training/post-training/RL distinction is becoming muddy, and a clearer framework is two paradigms: supervised learning (next-token prediction) and RL, with RL growing increasingly important.

### Compute Allocation Trends [13:38](https://www.youtube.com/watch?v=xbPriQWXtWM&t=818s)
Referencing an interview with the head of Xiaomi's MiMo Labs, Singh notes that pre-training and post-training now receive roughly equal compute. Kimi's Composer 2.5 takes this further, allocating more RL compute than supervised learning compute. This shift suggests supervised learning should be viewed as preparation for RL—building useful representations—rather than as the bulk of what defines the model.

### Supervised Learning as Atomic Skills for RL [14:40](https://www.youtube.com/watch?v=xbPriQWXtWM&t=880s)
Singh cites research showing that the base model needs exposure to "atomic skills" that it can later compose during RL, provided the environment has sufficient difficulty. He includes the classic AlphaGo graph where RL eventually surpasses supervised learning, noting it is unclear whether the same will happen for language models given the complexity of human language, but the trend toward more RL and less supervised learning makes the "atomic skills" framing increasingly valuable.

### Novel Data and Test-Time Compute Preparation [15:41](https://www.youtube.com/watch?v=xbPriQWXtWM&t=941s)
Some labs are introducing novel data shapes during supervised learning—such as reasoning traces, which do not resemble typical human output—and warming models up to test-time compute schemes during SFT or even pre-training. Singh references Zephyr's Ziya-1 paper as an example of how data design can shape the skills needed for effective RL exploration.

### Conclusion: From World Knowledge to Reasoning Priors [16:43](https://www.youtube.com/watch?v=xbPriQWXtWM&t=1003s)
Singh concludes that base models have shifted from encoding general human knowledge and world priors to building priors for reasoning and agentic behavior. While this is somewhat reductive—reflecting the current dominance of reasoners and agents—it suggests that if a new interaction paradigm emerges, the base model should be designed as a prior for that paradigm rather than as a massive scrape of web text.
