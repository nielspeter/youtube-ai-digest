# Opus 5 Beats Fable... at Half the Price?

[![Opus 5 Beats Fable... at Half the Price?](https://i.ytimg.com/vi/56wK2ttgIsc/hqdefault.jpg)](https://www.youtube.com/watch?v=56wK2ttgIsc)

[Watch on YouTube](https://www.youtube.com/watch?v=56wK2ttgIsc) · **Better Stack** · 2026-07-24

## TL;DR
Anthropic's new Claude Opus 5 nearly matches or exceeds the more expensive Claude Fable 5 on many coding and agentic benchmarks, while costing roughly half as much per task. In hands-on tests building an F1 game and a finance dashboard, Opus 5 produced the best UI and code choices, though its real-world API costs were closer to Fable than benchmarks suggest.

## Key Takeaways
- Opus 5 is positioned as a daily-use model that approaches Fable 5's frontier intelligence at roughly half the price, becoming the default on Claude Max and the strongest on Claude Pro.
- On Anthropic's own benchmarks, Opus 5 is the new state-of-the-art for coding and knowledge work, beating Fable 5 by nearly 10% on Frontier Bench.
- Opus 5 scored 30.2% on ARC AGI — a massive jump from the previous high of 7.8% — exhibiting a novel capability of converting tests into algebraic notation for logical reasoning.
- Third-party benchmarks from Artificial Analysis place Opus 5 second on the coding index (just 0.3 points behind GPT 5.6 Soul Extra High), first on the agentic index, and first on the intelligence index.
- Per-task cost on Artificial Analysis shows Opus 5 at 72 cents cheaper than Fable 5; on Cursor Bench, Opus 5 Max matched Fable 5's score but cost $8 versus Fable's $17.
- Opus 5's API pricing is identical to Opus 4.8: $5 per million input tokens and $25 per million output tokens.
- In a local F1 racing game test, Opus 5 produced the best-looking cars and functional gameplay, though it used five times more tokens than expected, costing ~$12.99 (higher than Fable in this single run).
- In a full-stack personal finance dashboard test, Opus 5 delivered the best UI and a solid stack (React, React Router, Node SQLite, Express); Fable 5 was comparable but built its own routing library instead.
- GPT 5.6 Soul produced competitive UI but made odd infrastructure choices (Cloudflare, Vinex) and had track-breaking issues in the game test; Kimmy K3 was impressive for an open-weight model but stored data in a JSON file instead of using a real database.
- Opus 5 has slightly less strict cybersecurity guardrails than Fable 5 — it can find vulnerabilities in source code but blocks binary-based scanning, penetration testing, and exploit generation, with classifiers intervening ~85% less often.

## Detailed Breakdown

### Introduction and Anthropic's Positioning [00:00](https://www.youtube.com/watch?v=56wK2ttgIsc&t=0s)
Anthropic describes Opus 5 as a "thoughtful and proactive model" that comes close to Fable 5's frontier intelligence at half the price. It is the new default model on Claude Max and the strongest on Claude Pro plans. The presenter notes surprise at this positioning, having expected Fable to become Anthropic's primary focus with Opus becoming a lighter "Sonic" model.

### Benchmark Performance [00:31](https://www.youtube.com/watch?v=56wK2ttgIsc&t=31s)
On Anthropic's own benchmarks, Opus 5 wins decisively — nearly 10% better than Fable 5 on Frontier Bench. Its ARC AGI score of 30.2% is the standout, dwarfing the previous high of 7.8% (held by "Soul") and Opus 4.8's 1.5%. The ARC AGI team observed Opus converting tests into algebraic notation for advanced logical reasoning, a capability not seen in other models. Fable is absent from ARC AGI due to its data retention policy, while Opus 5 has no data retention requirements for general access.

### Third-Party Benchmarks [01:32](https://www.youtube.com/watch?v=56wK2ttgIsc&t=92s)
Artificial Analysis places Opus 5 second on the coding index (0.3 points behind GPT 5.6 Soul Extra High, 1.5 points ahead of Fable 5), first on the agentic index, and first on the intelligence index. The presenter gives a shout-out to Kimmy K3 for breaking up the big players. On cost-per-task, Opus 5 is 72 cents cheaper than Fable 5, though GPT 5.6 Soul remains the best price-to-performance value at roughly half Opus 5's cost. Cursor Bench mirrors these results: Opus 5 Max matches Fable 5's score but costs $8 versus $17.

### Pricing and Strategy [02:34](https://www.youtube.com/watch?v=56wK2ttgIsc&t=154s)
Opus 5's API pricing matches Opus 4.8 at $5/M input and $25/M output tokens. The presenter plans to use Opus 5 for ~95% of work to conserve Fable 5 credits, reserving Fable for genuinely long-horizon, hard problems. He acknowledges GPT models and Kimmy K3 occupy the most attractive price-performance quadrant, while Anthropic models sit in the higher-price zone.

### Local Test 1: F1 Racing Game [03:38](https://www.youtube.com/watch?v=56wK2ttgIsc&t=218s)
The presenter asked each model to build a complete F1 racing game in a single HTML file using Three.js. Opus 5 produced the best-looking cars and functional gameplay (lap times, positioning, collision, gravel traps), despite a backwards track layout. Fable 5 also did well with a nice camera wobble but had more basic cars. GPT 5.6 Soul had no visible track and the track broke mid-way. Kimmy K3 was impressive for an open-weight model, comparable to GPT 5.6 Soul. However, Opus 5 took 46 minutes 51 seconds and cost ~$12.99 — more expensive than Fable due to using five times more tokens, which the presenter hopes is an outlier.

### Local Test 2: Finance Dashboard [05:43](https://www.youtube.com/watch?v=56wK2ttgIsc&t=343s)
Models were tasked with building a full-stack personal finance dashboard. Opus 5 delivered the best UI with fully functional separate pages, using React, React Router, Node SQLite, and Express. Fable 5 was comparable but built its own routing library rather than using React Router. GPT 5.6 Soul matched Opus on UI quality but used a single-page approach and an unusual stack (Next.js, Drizzle, Cloudflare, Vinex) — the presenter suspects this reflects OpenAI's internal infrastructure choices. Kimmy K3's UI was slightly behind, and it lost points for storing data in a JSON file instead of using a real database. Fable was the most expensive at $30.79 (56m 55s), with Opus close behind at $29.82 (59m 15s); GPT models were roughly 3.5x cheaper.

### Cybersecurity Guardrails [09:18](https://www.youtube.com/watch?v=56wK2ttgIsc&t=558s)
Opus 5's safeguards are similar to Opus 4.8 but with stronger guardrails on a narrow range of cyber tasks. It can find vulnerabilities in source code but blocks binary-based vulnerability scanning, penetration testing, and exploit generation. Classifiers intervene approximately 85% less often than they do for Fable 5.

### Competitive Landscape and Closing [09:50](https://www.youtube.com/watch?v=56wK2ttgIsc&t=590s)
The presenter highlights the current competitive dynamics: GPT 5.6 is driving prices down, open-weight models like Kimmy K3 are matching the big players in intelligence, and Anthropic is continuously pushing intelligence further. He encourages viewers to share their favorite model in the comments.
