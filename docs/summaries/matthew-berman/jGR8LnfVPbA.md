ChatGPT now has native voice mode within Codex, accessible via a button in a new chat. You can speak commands to spin up new threads, assign tasks, and manage multiple agents without typing. Berman shows it creating a separate thread for a 100-word poem and notes you can run all threads and agents through voice indefinitely.

### Publishing with ChatGPT Sites [02:50](https://www.youtube.com/watch?v=jGR8LnfVPbA&t=170s)
The built-in "Sites" feature publishes content—spreadsheets, PowerPoints, portfolios, or even a poem—to a web URL. By default the site is private, but a simple "make it public" command generates a shareable link. These URLs can be given to other agents so they can access whatever you published, making it a useful handoff mechanism between systems.

### Pinning Threads [03:40](https://www.youtube.com/watch?v=jGR8LnfVPbA&t=220s)
You can pin important chats to the top of the left sidebar by right-clicking or clicking the pin icon. Berman uses pinning to keep active and significant project conversations from getting buried as new threads accumulate.

### Model Selection and Thinking Effort [04:38](https://www.youtube.com/watch?v=jGR8LnfVPbA&t=278s)
Choosing the right model conserves your fixed weekly quota and improves quality. Berman primarily uses GPT 5.6 Luna for fast, inexpensive tasks and 5.6 Soul for complex work. Within Soul, he typically selects medium, high, or extra-high thinking effort. For example, he uses Soul to build a website and Luna for fine-tuning like font or color changes.

### Scheduled Tasks [07:14](https://www.youtube.com/watch?v=jGR8LnfVPbA&t=434s)
The "Scheduled" tab houses recurring tasks that run automatically. Berman runs three daily: stale file cleanup suggestions, a production log review for his "Astro" project, and a health check on forwardfuture.com. Tasks can run in new or existing chats and be grouped into projects. Because Luna is so inexpensive, you can schedule many daily automations—like a morning summary of calendar, email, and priorities—at nearly no cost.

### Plugins [09:40](https://www.youtube.com/watch?v=jGR8LnfVPbA&t=580s)
Plugins give ChatGPT native access to apps you already use—GitHub, Google Drive, Gmail, Calendar, Notion, Linear, Dropbox, and more. Instead of guessing how an app works, ChatGPT interacts with it directly, making tasks like email checking or document editing far more reliable.

### Skills [10:40](https://www.youtube.com/watch?v=jGR8LnfVPbA&t=640s)
Skills capture repeatable workflows so you don't have to retype long prompts. Invoke them by typing `/` and selecting from the list. You can create your own (e.g., a camera-research skill generated from an existing thread) or browse skills others have published. They are ideal for processes you repeat often but don't necessarily schedule.

### Long-Running Agents with /goal [11:55](https://www.youtube.com/watch?v=jGR8LnfVPbA&t=715s)
The `/goal` command tells ChatGPT to keep running until it achieves a defined objective. Goals can be verifiable ("make my website 50% faster") or LLM-judged ("make it as fast as possible"). Berman has had agents run for days using this feature and cautions users to set limits, such as a maximum runtime. He also references a linked loop library for goal inspiration.

### Quota Management [13:28](https://www.youtube.com/watch?v=jGR8LnfVPbA&t=808s)
Heavy users should monitor their weekly quota by clicking their name and usage percentage. Berman shows he has already exhausted his quota with three days until reset. In settings under "Usage and Billing," you can view your plan, balance, and any banked resets—temporary quota top-ups the ChatGPT team provides. These resets expire, so check expiration dates and use them before they vanish.

### Cross-Thread Visibility and Delegation [14:46](https://www.youtube.com/watch?v=jGR8LnfVPbA&t=886s)
A single thread can access all your other threads, summarize them, search them, and even delegate work to them. Berman demonstrates asking a thread to find a recent poem-related conversation; it locates two threads and links him to one. He then sends a new request from his current thread to that poem thread, which generates a 50-word poem—showing how threads can orchestrate each other within one unified system.

### Local, Cloud, and Connections Usage [16:35](https://www.youtube.com/watch?v=jGR8LnfVPbA&t=995s)
- **Local**: Run ChatGPT directly on your computer; all agent activity stays on your machine.
- **Cloud**: Place a coding project in a cloud environment so Codex can run, execute, and edit code on a remote server, enabling more parallel agents without slowing down your home computer.
- **Connections**: Remotely connect to your desktop ChatGPT from any device. Berman sets this up in Settings under Connections by enabling "Control this Mac" and scanning a QR code with his phone. Once linked, his phone shows a remote tab connecting to his Mac Studio, giving him access to all desktop threads from anywhere.
